Clear boundaries

What this page
does not do.

01

No Django backend

GitHub Pages serves static files. Accounts, uploads, databases, and server-side actions are not available here.

02

No persistence or tracking

Demo activity stays in page memory and disappears when you refresh or close the tab. This site makes no analytics or API calls.

03

No proof of impact

Sample records and simulated votes do not verify bottle provenance, real people, environmental outcomes, payments, AI, or blockchain activity.
